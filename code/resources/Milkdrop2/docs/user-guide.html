User Guide

MilkDrop turns whatever your computer is playing into a live, GPU-driven visual journey. This guide covers running it, every keyboard shortcut, and the files it uses.

Windows 10 / 11Direct3D 99,795 presets includedWorks with any audio player

Getting started #

1

Play some music

Use any player: Spotify, a browser, VLC, a game. MilkDrop listens to your default playback device.

2

Run MilkDrop3.exe

No installation. Keep the plugins folder next to the exe. Only one copy runs at a time: starting MilkDrop again brings the running copy forward.

3

Go fullscreen

Double-click the picture or press Alt+Enter. Press F1 for the built-in help.

MilkDrop captures the sound through WASAPI loopback: it records what goes to the default playback device in Windows (Settings, System, Sound, Output). To visualize a different device (for example headphones instead of speakers), make that device the default.

No sound, no motionWindows only delivers loopback audio while something is actually playing. With silence the visuals keep running, but they won't react to the beat.

Letter keys are case-sensitive where both are listed: lowercase decreases, Shift+letter increases. Use the digits at the top of the keyboard, not the numeric keypad.

Effects #

Effects change how the finished picture looks, whatever preset is playing. Right-click the picture (or press Shift+F10) and open the Effects submenu. Each effect is a check item: click it to switch it on, click again to switch it off. You can combine several.

  • There are 11 effects, plus Brightness and Contrast controls to make the picture lighter, darker, flatter or punchier.
  • Effects stay on when the preset changes, so you can pick a look and let the presets flow underneath it.
  • Effects are not saved into presets. When you press S, MilkDrop removes them first, so the saved file is the plain preset.
  • The menu has an item to clear every effect at once.

Desktop background #

Desktop mode puts the visuals behind your desktop icons, like an animated wallpaper. To switch it on, right-click the picture and choose View, Run as desktop background, or press Ctrl+Alt+Shift+D. The same keys switch it off again.

  • While the mode is on, MilkDrop shows an icon in the notification area (system tray). Right-click it for a short menu. Double-click it to return to a normal window.
  • The picture covers all of your monitors.
  • When you leave the mode or quit, your normal wallpaper comes back.
  • While the mode is on, keys and mouse clicks go to the desktop, not to MilkDrop. Use the tray icon or Ctrl+Alt+Shift+D.
  • If another program already uses Ctrl+Alt+Shift+D, MilkDrop says so when it starts; the menu item still works.
  • If Explorer restarts, MilkDrop restarts itself and returns to the desktop background within a few seconds.
  • Starting MilkDrop again brings the running copy forward. While it is on the desktop, it tells you to press Ctrl+Alt+Shift+D to bring it back.
Your wallpaper settingsMilkDrop never changes your wallpaper setting. A slideshow, Windows Spotlight or a different wallpaper on each monitor keeps working; when you leave the mode, Windows shows your wallpaper again.

Working with presets #

A preset is a small text file (.milk) describing motion, waveforms, shapes, and two pixel shaders. MilkDrop shows one preset at a time and blends to the next one every few seconds, or cuts hard on a loud beat.

  • Presets live in plugins\Milkdrop2\presets\ next to the exe. Sub-folders show up in the browser (L), so you can sort presets into folders.
  • To add presets, drop them on the window (see Drag & drop presets), or copy .milk files (and any textures they ship with) into that folder.
  • To stay on a preset you like, lock it with ` or Scroll Lock. Set the auto-change time with F3.
  • Presets your graphics card can't run (shader model too high) are hidden from the list.

Ratings

Each preset has a rating from 0 to 5. Higher-rated presets are picked more often at random, and a preset rated 0 is never picked at random. Press F6 to see the rating and + / - to change it. The rating is saved into the preset file right away. To bring back a preset rated 0, open it with L and press +.

Shader locks & mash-ups

Every preset has a warp shader (shapes how the picture moves and evolves) and a composite shader (the final look on screen). D locks one or both of them; while locked, loading a new preset keeps your locked shader and takes everything else from the new preset. That's a quick way to find new combinations. A, ! and @ do this randomly. The full mash-up screen in the M menu lets you build a preset from five parts of different presets. Save any result you like with S.

Playlist #

Normally every preset in your library can come up. The Playlist screen (P, or Preset > Playlist... in the right-click menu) limits that to the presets you pick: Space, H, Backspace and the automatic changes then stay inside the playlist. It has two lists side by side: Not playing on the left and Playing on the right. At first everything is in Playing.

Drag & drop presets

Drag a folder or .milk files from Explorer onto the MilkDrop window:

  • A folder gives the .milk files directly inside it (not those in its sub-folders).
  • Images are not presets: the message Images: load from settings appears (use Sprites > Load image...).
  • A preset is already in your library when presets\ has a file with the same name and the same size. Those are used as they are; nothing is copied.
  • New presets are listed first in a new presets window, all checked. Up / Down move, Space checks or unchecks one, Ctrl+A checks all (or none), Enter copies the checked ones into presets\, Esc skips all of them. A new preset whose name is taken by a different file gets a numbered name, for example Galaxy (2).milk; nothing is ever overwritten.
  • Textures that a copied preset uses are copied too, when they sit next to it (or in a textures folder next to it), into plugins\Milkdrop2\textures\. A texture is never overwritten, and never copied when your presets would already find a texture with that name (any image type, in textures\ or in presets\), so the presets you have keep looking the same. Those are counted in the message N textures kept (name already used).
  • One .milk file loads right away (after the new-presets window when it is new); your playlist does not change.
  • A folder or several files become the playlist for this session, and their first preset starts. Open P to see or change it.
  • While a screen, menu or prompt is open, a drop is refused with Close the open screen first.

Sprites #

Sprites are images (PNG, GIF, JPG, BMP, TGA, DDS) drawn on top of the visuals: a logo, a photo, a sticker. All sprite commands are in the right-click menu under Sprites.

Add, move and resize

  • Sprites > Load image... picks an image file and puts it in the middle of the screen. PNG and GIF files keep their transparent parts; black parts of the image stay black (no colour key).
  • Drag a sprite with the left mouse button to move it. It follows the cursor exactly, in any window shape.
  • Turn the mouse wheel over a sprite to make it bigger or smaller. Over the visuals (not on a sprite) the wheel and the mouse do what they did before.
  • The last sprite you loaded, clicked or resized is the selected one. Sprites > Blend changes how it is drawn: Image transparency (uses the PNG/GIF transparency, the default for loaded images), Alpha blend, Decal, Additive, Colour mask or Colour key. The current mode has a check mark.
  • Sprites > Remove selected and Remove all take sprites off the screen.

Saving sprites with a preset

When you save a preset (S), the sprites on screen are saved in it: the image, where it is, its size, rotation, blend mode and colour key. They go into the .milk file as suri_sprite... lines after the other settings. From then on these sprites belong to that preset: when another preset loads they go away, and when that preset loads again they come back in the same place and at the same size. Sprites you add and don't save with a preset stay on screen when the preset changes. A preset without sprites is saved exactly as before.

A sprite saved into a preset keeps its position, size, rotation, blend mode and colour key; it does not keep flips, colour or transparency changes made by code, or motion code. With Image transparency and colour key 0x000000, a sprite has no colour key, so black parts of the image stay black (this is how images from Load image... are saved). With any other blend mode, or another colour key, that colour becomes transparent as in milk2_img.ini.

Sprites stay on screen when you resize the window, maximise it, switch to full screen or desktop mode. A sprite from milk2_img.ini that moves by its code comes back as a still picture where it was at that moment.

Sprites from Load image... and from presets are drawn on top of the visuals only; they are not painted into the picture, so moving one leaves no trail.

Images inside the plugins\Milkdrop2 folder are saved with a relative path, so the preset still works if you move the whole MilkDrop folder. Images elsewhere are saved with their full path. If an image is missing when the preset loads, you see one error message and the preset loads without that sprite.

Sprites with code: milk2_img.ini

For sprites that move, fade, spin and react to the music, define up to 100 of them in milk2_img.ini next to the exe. Sprites > Edit sprite list... creates the file with two examples (if it doesn't exist yet) and opens it in Notepad. Launch one with K and its two-digit number, or with Sprites > Launch from list... and then the two digits (a short message asks for them).

The init_ and code_ lines of these sprites now run as written, and each image is shown with its real aspect ratio. (In MilkDrop 2 a bug stretched sprites in windows that weren't 4:3; that is fixed.)

; milk2_img.ini - sprite 00: a logo that pulses with the bass
[img00]
; the image: relative to plugins\Milkdrop2\, or a full path
img=textures\logo.png
; this color becomes transparent
colorkey=0x000000
; init_ lines run once, when the sprite starts
init_1=x=0.5; y=0.5; a=0;
; code_ lines run every frame
code_1=a = min(1, time*0.5);
code_2=sx = 0.4 + 0.1*bass; sy = sx;
code_3=rot = time*0.3;

Put comments on their own line, starting with ;. A comment after a value on the same line becomes part of the value, and the line stops working.

VariableMeaning
x, yCenter position, 0..1 (0.5 = middle of the screen)
sx, syScale (1 = fit the screen)
rotRotation in radians
r, g, b, aColor tint and opacity, 0..1
flipx, flipy1 = mirror horizontally / vertically
repeatx, repeatyHow many times the image tiles
blendmode0 blend, 1 decal, 2 additive, 3 source color, 4 color key, 5 image transparency (the PNG/GIF alpha)
burn1 = also paint the sprite into the image, so it leaves trails
doneSet to 1 to remove the sprite
time, frame, fps, progressRead-only: time since the sprite started, frame counter, frame rate, preset progress
bass, mid, treb (+ _att)Read-only: current audio levels (1 = average)

Custom messages #

Custom messages are short texts you can flash on screen, for example a DJ name or an event title. Define up to 16 fonts and 100 messages in milk2_msg.ini next to the exe. The commands are in the right-click menu under Messages:

  • Edit messages... creates milk2_msg.ini with an example (if it doesn't exist yet) and opens it in Notepad. The file is saved as UTF-16 ("Unicode" in Notepad), so messages can be in any language, Hebrew included. Keep that encoding when you save.
  • Random message shows one of your messages. Edits you saved are picked up without restarting. With no messages yet you get a short hint instead.
  • Show message..., or Y and the two-digit number, shows a message by number.

To show messages at random by themselves, set fTimeBetweenRandomCustomMsgs in milk2.ini to the average number of seconds between messages (-1 turns this off).

[font00]
face=Arial
bold=1
ital=0
r=255
g=255
b=255

[message00]
text=MilkDrop 3.0.S
font=00
size=40        ; text height
x=0.5          ; position, 0..1
y=0.5
time=4         ; seconds on screen
fade=0.3       ; part of that time spent fading in
growth=1.2     ; grows (or shrinks below 1) while showing
randx=0.1      ; random position jitter
randr=60       ; random color jitter (also randg, randb)

A message can also override its font's face, bold, ital, r, g and b.

Now playing #

When a new song starts, MilkDrop shows Artist – Title on screen. It reads the song from Windows itself, so it works with any player that shows up in the Windows media controls (the box that appears next to the volume when you press a media key): Spotify, YouTube or another site in your browser, and most music and video players. Nothing to set up.

  • Press T to show the current song again.
  • Pausing and resuming doesn't show it again; only a new song does.
  • To turn it off (or on again), right-click and pick View → Show now playing. The choice is saved (bNowPlaying in milk2.ini).
  • If no player is open, nothing is shown. On Windows versions without media controls the menu item is greyed out.

Troubleshooting #

The visuals don't react to the music

  • Check that the music plays through the default playback device in Windows. MilkDrop listens only to that one.
  • Open MilkDrop3.log: it names the device and the audio format MilkDrop opened.
  • Close audio "enhancement" or recording tools that take the device exclusively, then restart MilkDrop.

The window opens and closes immediately

Look at the last lines of MilkDrop3.log. Keep D3DX9_43.dll, D3DCompiler_43.dll and the plugins folder next to the exe.

It's slow or choppy

  • Lower the frame-rate limit with F2, or run in a smaller window.
  • Lower nMeshSize in milk2.ini (for example to 48).
  • Update your graphics driver. Most visual glitches are driver issues.

It always shows the same preset

The preset is locked: press ` or Scroll Lock, or press F3 until a time appears instead of "unlimited".

Some presets are missing from the list

Your graphics card doesn't support the shader model those presets need, so MilkDrop hides them. Setting MaxPSVersion=3 in milk2.ini makes it try harder.

Known limitations in 3.0.S #

  • Audio comes from the default device only. If you change the default device while MilkDrop runs, restart it.
  • No settings window. Settings are in milk2.ini.
